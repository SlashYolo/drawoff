# Drawoff — Летопись в картинках

Онлайн-игра для компании: нейросеть сочиняет сказание в духе средневековья, игроки рисуют к нему иллюстрации, книга перелистывается прямо в браузере, а затем все ставят лайки лучшим рисункам.

## Как играть

1. Введите имя и нажмите **«Играть»** — создастся комната. Друзья входят по **коду комнаты** (или по ссылке).
2. Хозяин комнаты начинает игру (от 2 до 8 игроков).
3. Нейросеть пишет историю: **одна страница на каждого игрока**.
4. **1 минута** на чтение. Каждый может (но не обязан) выбрать страницу, которую хочет нарисовать.
   Если одну страницу выбрали несколько человек — бросается монетка (жребий), а проигравший получает оставшуюся страницу. Кто ничего не выбрал — получает свободную страницу случайно.
   Если все нажали «Готов», рисование начинается раньше.
5. **3 минуты** на рисование. Когда время выходит, рисунок сдаётся автоматически.
6. Книга перелистывается страница за страницей: слева текст, справа иллюстрация.
7. Голосование: лайки любым рисункам, кроме своего. Больше всех лайков — «Придворный живописец».

## Инструменты рисования

- Кисть и ластик, **толщина** (1–80) и **прозрачность** (5–100 %) ползунками.
- **Прямые линии** (с Shift — шаг 15°), **прямоугольник, эллипс, треугольник** — контуром или с заливкой (с Shift — квадрат/круг).
- **Заливка** области (с допуском по цвету).
- **Пипетка**.
- Цвет: активный цвет показан прямоугольником над инструментами; по нажатию открывается **цветовой круг RGB** (оттенок и насыщенность) с ползунком яркости, полями R/G/B и HEX и готовой палитрой.
- Инструменты расположены слева от холста, ползунки толщины и прозрачности — под холстом.
- Отмена/повтор (Ctrl+Z / Ctrl+Y), очистка холста.
- Горячие клавиши: B — кисть, E — ластик, L — линия, R — прямоугольник, O — эллипс, T — треугольник, F — заливка, I — пипетка, `[` / `]` — толщина.
- Работает мышью, пером и пальцем (Pointer Events).

## Генерация историй

Истории пишет Claude по заготовленному промпту, в который каждый раз подставляется новое «семя»:
герой, спутник, место, время, цель, противник, препятствие, волшебный предмет, поворот сюжета, жанр, тон и манера рассказчика
(`server/stories/seeds.js`). Число комбинаций — около 10¹⁵, так что даже миллион историй не повторится.
Недавние семена запоминаются, чтобы не выпадать повторно.

Если ключ API не задан или нейросеть не ответила вовремя, та же комбинация собирается в историю
встроенным офлайн-генератором (`server/stories/procedural.js`) — игра не останавливается.

## Запуск

Нужен Node.js 18+.

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
# откройте http://localhost:3000
```

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `ANTHROPIC_API_KEY` | — | Ключ Claude API. Без него работает офлайн-генератор |
| `STORY_MODEL` | `claude-opus-5` | Модель для генерации историй |
| `STORY_TIMEOUT_MS` | `25000` | Сколько ждать нейросеть, прежде чем перейти на офлайн-генератор |
| `STORY_AI` | — | `off` — всегда использовать офлайн-генератор |
| `READ_SECONDS` | `60` | Время на чтение |
| `DRAW_SECONDS` | `180` | Время на рисование |
| `MIN_PLAYERS` | `2` | Минимум игроков для старта (`1` — для одиночной проверки) |

## Разработка

```bash
npm run dev   # перезапуск сервера при изменениях
npm test      # тесты распределения страниц и генератора историй
```

Структура:

- `server/index.js` — HTTP-сервер (Express) и Socket.IO.
- `server/game.js` — комнаты, фазы игры, таймеры, жребий, голосование.
- `server/stories/` — семена, запрос к нейросети и офлайн-генератор.
- `public/` — клиент: `js/app.js` (экраны), `js/paint.js` (рисовалка), `css/style.css` (оформление).

Оформление: современный светлый интерфейс на шрифте Open Sans. Средневековый стиль (пергамент, кожаный переплёт, буквицы) оставлен только у книги, которая перелистывается в конце раунда; текст в книге набран шрифтом Amatic SC. Оба шрифта поддерживают кириллицу.
